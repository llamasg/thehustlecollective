# Homepage Redesign: Electric Youth

## Color Palette
- Primary: `#b8e600` (Vivid Chartreuse)
- Accent: `#ff6b6b` (Hot Coral)
- Dark: `#000000` (Pure Black)
- Light: `#f5f0e8` (Warm Cream)
- Mid: `#1a1a1a` (Near Black)

## Hero
Full-viewport mouse cursor image trail. Large festival photos scatter as cursor moves. Centered "THE HUSTLE COLLECTIVE" text in cream with "HUSTLE" highlighted in chartreuse. Mobile fallback: static grid of images at low opacity.

## Manifesto Strip
Full-width chartreuse background, black text: "building communities since '06". Large uppercase type.

## Sections (palette swap)
- ImpactStats: Chartreuse stat values, cream labels on black
- Festival Grid: Chartreuse hover borders, coral category tags
- Editorial Gallery: Chartreuse accent lines
- Testimonials: Coral quotation mark accent
- Blog Preview: Coral category badges, chartreuse links
- Partners: Chartreuse section accents

## Typography
Same Helvetica Now system, bolder weight contrasts. Display: bold uppercase tracked wide. Manifesto: light weight very large.
